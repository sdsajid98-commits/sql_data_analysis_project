# SQL Data Analytics Project

A curated set of SQL scripts for exploring, analyzing, and reporting data inside relational databases.

This project focuses on practical SQL patterns used in real analytics work:
exploration, segmentation, time trends, cumulative metrics, and performance analysis.

---

## 📊 What’s inside

- Database exploration & profiling  
- KPI / measures building  
- Time-based trend analysis  
- Cumulative & rolling calculations  
- Segmentation & classification logic  
- Part-to-whole analysis  

Each script is designed to be reusable, readable, and analysis-driven.
